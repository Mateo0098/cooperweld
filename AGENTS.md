# Instrucciones del proyecto

- El alcance analítico es exclusivamente el método Wenner de cuatro picas.
- No mezclar lecturas de dos picas, tres picas o pinzas.
- Conservar intactos los DOCX originales y sus fotografías embebidas.
- Toda cifra derivada debe regenerarse desde `datos_procesados/wenner_4_picas_transcripcion.csv`.
- Ejecutar `python -m unittest discover -s pruebas -v` antes de publicar.
- No usar `git push --force`.
